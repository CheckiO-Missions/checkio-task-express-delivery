我们的三个机器人在岛上发现了几个神秘的盒子。经过一番检查，尼古拉发现这些 这些盒子有一个有趣的功能。如果你在其中一个箱子里放了东西，你就可以从其他任何箱子里再取出来。 斯蒂芬认为，这样就可以在岛上快速运送货物，使货物运输速度提高一倍。 斯蒂芬可以把货物放在一个箱子里，然后再到交货地点取货。 地图上有一些斯蒂芬无法通过的水牢，但如果有了这些箱子，他的任务就会轻松很多。 更轻松。

交货地图以字符串数组的形式显示，其中

  • "W "表示水（封闭式）。
  • "B" 是盒子
  • "E" 是一个目标点。
  • S "是起始点。
  • ". "为空单元格。

如果斯蒂芬带着行李，两分钟内就能在相邻的牢房之间移动。如果不带任何随身行李，他只 分钟。 将货物装入（和取出）箱子需要一分钟。 您应该找到最快的货物运送方式（最短时间）。

路线是一个字符串，每个字母代表一个动作。

  • "U" -- 向上（北）
  • "D" - 下（南）
  • "L" -- 左（西）
  • "R" -- 右（东）
  • "B" -- 装（卸）箱。

输入： 以字符串列表形式交付的地图。

输出： 以字符串形式显示的最快路线。

示例 

checkio(["S...","....","B.WB","..WE"]) #RRRDDD
checkio(["S...","....","B..B","..WE"]) #DDBRRRBD

使用方法 这个问题与 "开放式迷宫 "类似，但这里有不同的移动成本。 通过这个任务，你可以学习寻路和图形遍历中使用的算法。 例如：在一些战略或角色扮演游戏中，一个单位在不同地形上的移动速度是不同的。

前提条件是 0 < 行 < 10
0 < 列 < 10
∀ x,y∈ 坐标 ：0 < x,y < 10
